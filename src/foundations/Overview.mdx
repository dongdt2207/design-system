# Ebig Design System

The source of truth for the interface of Ebig products. Everything here is **real code, running**.

Style: **editorial calm** — cream background, warm ink, one accent used sparingly, large headings at weight 400, depth from hairlines instead of shadows, radii of 8 and 12. Reference in `docs/style-reference.md`.

## How to use it

**Designer**
- Before drawing a new screen, look through *Components* and *Sections*.
- Figma Variables share names with the tokens under *Foundations*. Never type a color or a number by hand.
- Figma component properties share names with the props.
- Review the result here; the **Design** tab shows the Figma frame beside the story.

**Developer**
- Components use semantic tokens only (`--color-bg-brand`), never primitives (`--brand-500`), never raw hex.
- Each component: `Name.tsx` + `Name.css` + `Name.stories.tsx`.
- One story per visible state. The **Accessibility** tab must be clean before merging.

Switch themes with the toolbar button.
