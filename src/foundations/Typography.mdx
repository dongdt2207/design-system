# Typography
One family (`--font-sans`, Inter), with mono reserved for code (`--font-mono`, JetBrains Mono). Change the font in `tokens.css`.

## Scale
<TypeScale sizes={['3xl', '2xl', 'xl', 'lg', 'md', 'sm', 'xs']} />

## Weight
Three levels: regular (400) for body copy **and display headlines**, medium (500) for labels and buttons, semibold (600) for component headings. No bold — the editorial voice depends on it.

## Display (landing pages)
`--display-lg` 72 · `--display-md` 36 · `--display-sm` 26, weight 400, tracking `--tracking-tight` (-0.02em).
