# Colors

Two layers. **Primitive** is the raw palette (`--gray-*`, `--brand-*`, used only inside `tokens.css`). **Semantic** is color by meaning, changing with the theme — components use this layer only. The background is cream and the ink is a warm brown-black; there is no pure white or absolute black.
